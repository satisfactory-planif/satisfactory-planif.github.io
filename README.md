# Planificateur Satisfactory

**https://faimer-org.github.io/satisfactory-planif/**

Planificateur de production pour Satisfactory 1.2, en français, à partir des données officielles du jeu.

- **Fiche pièce** : de quoi une pièce est faite, dans quelle machine, où elle sert, et les recettes alternatives.
- **Mon usine** : pour les pièces et débits voulus, chaque étape jusqu'aux ressources brutes, le nombre de machines, l'énergie et les sous-produits. Un lien permet de partager l'usine.
- **Transport** : combien de tapis, de wagons ou de drones pour acheminer les ressources.

Fonctionne dans le navigateur, sans compte ni installation ; votre usine reste enregistrée sur votre appareil.

## Droits

Les noms, données et icônes du jeu appartiennent à Coffee Stain Studios. Les icônes proviennent du projet [SatisfactoryTools](https://github.com/greeny/SatisfactoryTools). Projet de fan, non affilié à Coffee Stain Studios.
